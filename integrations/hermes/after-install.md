# Oída listening installed

Run /oida status to inspect the local gateway. The oida:oida-listening skill
explains when Hermes should use its own audio-input model and when Oída should
run its configured local model.

The installer also registers the Oída MCP server. Earworm and Akousmata remain
a specialized sonic-memory sidecar, so they complement Hermes general memory
instead of replacing the user's selected provider.

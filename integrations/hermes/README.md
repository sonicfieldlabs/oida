# Oída for Hermes

This native Hermes plugin adds one namespaced skill and the /oida command.
The oida integrate hermes command copies it to the active Hermes profile,
enables it, and registers Oída as a stdio MCP server.

Oída's Earworm and Akousmata memory is deliberately a sonic-memory sidecar.
Hermes can query it through MCP without replacing or competing with the
selected general-purpose Hermes memory provider.
